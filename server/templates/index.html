Perguntas frequentes

Antes de começar

Como o AEGIS detecta ameaças?

Em camadas: comparando o hash SHA-256 do arquivo com a base de assinaturas, procurando padrões de bytes conhecidos no conteúdo e aplicando uma análise heurística que soma pontos para sinais suspeitos. Se o ClamAV estiver instalado, ele também analisa os arquivos. Pontuação alta vira “malicioso”; os casos intermediários aparecem como “suspeitos” para você decidir.

O AEGIS usa o ClamAV?

De forma opcional. Se o ClamAV estiver instalado, o aplicativo o encontra sozinho (daemon clamd ou clamscan) e passa a usar as assinaturas dele junto com o motor próprio. Sem o ClamAV, o AEGIS continua funcionando só com o motor próprio, que é bem mais limitado. A proteção em tempo real usa o ClamAV apenas no modo daemon (clamd).

Preciso estar conectado à internet?

Para entrar na conta e atualizar as assinaturas, sim. As verificações em si rodam no seu computador e funcionam offline com as assinaturas já baixadas.

Como posso testar sem risco?

O aplicativo tem um botão que cria o arquivo de teste EICAR, um padrão inofensivo reconhecido por praticamente todo antivírus. Ao verificar a pasta, o AEGIS deve detectá-lo e movê-lo para a quarentena. Um segundo arquivo de teste só é detectado depois de atualizar as assinaturas, mostrando que a atualização funciona.

Em quais sistemas o aplicativo roda?

Windows, Linux e macOS com Python 3.9 ou superior (o Tkinter vem incluso no instalador oficial do Windows e do macOS). No pacote há scripts para abrir o app e para gerar um executável .exe no Windows.

Posso cancelar quando quiser?

Sim. No painel, em “Minha área”, o botão de cancelar volta sua conta ao plano Essencial na hora.

O pagamento é real?

Não. Este site é um projeto acadêmico: o checkout é simulado, nenhum valor é cobrado e os dados completos do cartão nunca são armazenados — guardamos apenas a bandeira e os quatro últimos dígitos para exibir no histórico.
