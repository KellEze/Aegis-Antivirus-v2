  3. Sem interface gráfica? Use python3 aegis_cli.py --help.

ClamAV — detecção de malware real

Recomendado

O AEGIS funciona sozinho, mas a base dele é pequena. O ClamAV é um antivírus de código aberto com milhões de assinaturas. Instalado, o app o detecta automaticamente e passa a usá-lo.

  1. Windows: instale o ClamAV, configure o freshclam.conf (copie o modelo .sample e comente a linha Example) e execute freshclam.exe para baixar a base.
  2. Linux (Debian/Ubuntu): sudo apt install clamav clamav-daemon, depois sudo freshclam e sudo systemctl enable --now clamav-daemon.
  3. macOS: brew install clamav e configure o freshclam.
  4. No app: Conta e ajustes → ClamAV → Detectar novamente e Testar ClamAV.

Os passos exatos variam conforme a versão: consulte docs.clamav.net. Com o clamscan, o ClamAV carrega a base a cada verificação (pode levar de dezenas de segundos a alguns minutos e usar bastante memória). Com o clamd a verificação é rápida e o ClamAV entra também no tempo real.
